🚀 HOW TO BUILD THE APK
═══════════════════════════════════════════════════════════════════════════

OPTION 1: Using Android Studio (EASIEST - Recommended)
────────────────────────────────────────────────────────────────────────────
1. Download Android Studio from https://developer.android.com/studio
2. Open Android Studio
3. Click: File → Open → Select project folder
4. Wait for Gradle sync (2-3 minutes)
5. Click: Build → Build Bundle(s)/APK(s) → Build APK
6. APK will be ready at: app/build/outputs/apk/debug/app-debug.apk

Time Required: ~5-10 minutes (includes download & sync)

OPTION 2: Using Command Line
────────────────────────────────────────────────────────────────────────────
Prerequisites:
✓ Java 17 installed
  - macOS: brew install openjdk@17
  - Ubuntu: sudo apt-get install openjdk-17-jdk
  - Windows: Download from oracle.com/java

Then run:
$ cd /home/infaira/Desktop/intership\ proj
$ ./gradlew assembleDebug

Time Required: ~3-5 minutes (first build)

📦 BUILD OUTPUT
═══════════════════════════════════════════════════════════════════════════
After successful build, you'll have:

✅ APK File: app/build/outputs/apk/debug/app-debug.apk
   - File Size: ~5-10 MB
   - Package Name: com.raithabharosa.hub
   - Version: 1.0.0
   - Ready to install on any Android 8.0+ device

📱 INSTALLING THE APK
═══════════════════════════════════════════════════════════════════════════
Option A: Via Android Studio
  → Click Run (▶️) button → Select device → Install

Option B: Via ADB Command Line
  → adb install app/build/outputs/apk/debug/app-debug.apk

Option C: Direct File Transfer
  → Copy APK to phone → Open in file manager → Tap to install
